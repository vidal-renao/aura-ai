## Business Context & Strategic Value

**Aura AI** is an AI-Powered Revenue Growth Management (RGM) SaaS platform tailored for the Swiss SME (KMU) sector. The system delivers autonomous multi-agent catalog auditing, dynamic pricing elasticity, SEO metadata generation, and a human-in-the-loop validation workflow — governed under strict data compliance standards (Swiss DSG / GDPR-compatible).

**Core value propositions:**

- Gross margin optimization via real-time AI analysis of stock risk and pricing elasticity
- Automated SEO metadata generation with Google SERP snippet preview before catalog deployment
- Full audit trail of all price changes (`pricing_logs`) with mandatory human approval gates
- Multi-tenant architecture with schema-level data isolation per organization

## Database Schema: `aura_core`

| Table | Purpose |
| :--- | :--- |
| `tenants` | Multi-tenant organization registry |
| `products` | Product catalog with dynamic pricing fields |
| `ai_insights` | AI-generated recommendations (`pending` / `applied` / `dismissed`) |
| `pricing_logs` | Immutable audit log of all approved price changes |

**Security model:** RLS enabled on all tables. Anon key reads via explicit policies. Service role bypasses RLS but requires explicit PostgreSQL GRANTs (`GRANT USAGE ON SCHEMA`, `GRANT SELECT/INSERT/UPDATE/DELETE ON ALL TABLES`).

## AI Engine Flow

```text
POST /api/aura/engine { tenant_id }
  → Fetch tenant + products (service_role, bypasses RLS)
  → Build system prompt with RGM business rules (stock_risk, dynamic_pricing, seo_optimization)
  → claude-sonnet-4-6 with forced tool_use: generate_revenue_insights
  → Structured JSONB insights array
  → Bulk insert into ai_insights (status: pending)
  → Human reviews in Insights inbox
      → Approve: applies price update + writes pricing_log
      → Dismiss: archives proposal
```
